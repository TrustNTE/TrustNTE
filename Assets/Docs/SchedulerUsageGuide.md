# 调度器使用指南

调度器把多个 JS 脚本串成「配置组」，按顺序自动执行——日常一条龙的基础设施。

## 三分钟上手

1. 先写脚本：「JS 脚本」页 → ➕ 新建 → 写好 → 💾 保存（脚本存于 UserData\Scripts）
2. 建分组：调度器页左下「新建分组」（双击分组名可重命名）
3. 加任务：右上下拉选脚本 → 「添加为任务」；同一个脚本可重复添加多次
4. 跑起来：▶ 运行当前组（或 ⏩ 连续执行全部分组）

## 按钮说明

| 按钮 | 行为 |
|---|---|
| ▶ 运行当前组 | 顺序执行组内所有启用的任务（每个按 RunNum 次） |
| ⏩ 连续执行全部 | 从第一个组跑到最后一个组（组间 1 秒缓冲） |
| ⤼ 跳过当前任务 | 只打断当前正在跑的，后续任务继续 |
| ⏹ 停止 | 整组全停 |

## 文件位置

- 配置组：UserData\Scheduler\{组名}.json（原子写，断电不损坏）
- 脚本：UserData\Scripts\*.js
- 配置组 json 可直接复制分享给别人

## 进阶字段（编辑组 json）

    {
      "Schema": 1,
      "Name": "我的日常",
      "Tasks": [
        { "Name": "领奖励", "Type": "JsScript", "Target": "daily.js",
          "RunNum": 3, "Enabled": true, "TimeoutSeconds": 60 }
      ]
    }

- RunNum：执行次数（UI 暂未暴露，改 json）
- Enabled：false 时整组跳过该任务
- TimeoutSeconds：单次执行超时秒数，0 = 不限时（靠手动停止）
- Type：JsScript / Shell（Target 写完整 cmd 命令行）/ KeyMouse（宏回放，待接入）

## 与实时触发的互斥

调度器跑组期间，实时触发页的后台触发器（剧情/战斗）启动会被自动拦截（任务车道协调器，「优先启动为准」）；反过来先开的实时触发也不会被调度器抢输入。

## 常见问题

- 下拉里没脚本？点「🔄 刷新」；确认脚本在 UserData\Scripts 且已保存
- 任务状态一直「执行中」？脚本里可能写了不带 sleep 的死循环，点 ⏹ 停止后检查脚本
- 任务失败？打开主窗口日志搜 [调度器]，异常信息带文件名和原因
